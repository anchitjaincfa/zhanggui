# 掌櫃 ZHANGGUI

**The shopkeeper who never forgets.**

An AI front desk for restaurants, built on the XTrace Memory API.
One memory spine, two mouths: the phone and the floor.

- **Front Desk** — answers the restaurant's phone, in the caller's language
- **Ghost CRM** — a regulars ledger that builds itself from calls and tickets
- **Secret Menu** — order like a twenty-year regular
- **Guardian** — the allergen layer kitchens forget

Built for the XTrace Mind Games hackathon, MenuSifu track. Stanford, July 2026.
